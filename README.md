# Explorateur de code

A first taste of programming for children around 5 years old — before they can read,
before they can type, before anyone has said the word "code" to them.

## The idea

A child picks pictures: go right, go left, go up, go down, sing.
Those pictures line up into a list. The list is the program.

Then the child presses play, and the story unfolds on its own: a robot reads the list
one picture at a time and passes each instruction along to the heroine, who walks across
a small world, avoids rocks, reaches the demon and sings it away.

Nothing is typed. Nothing is spelled. The child arranges pictures and watches what happens.

## What a child discovers

- **A program is a list of orders**, carried out one after the other, in the order you chose.
- **The machine only does what it is told** — nothing more, nothing clever, no guessing.
- **Being wrong is part of it.** Walking into a rock or off the edge stops the story;
  the child removes a picture, adds another, and tries again.
- **Order matters.** The same five pictures in a different order tell a different story.
- **Step by step.** The child can slow the program down, advance one instruction at a time,
  go back, and see exactly which order caused which movement.
- **Things you make can be kept.** A program can be saved under the child's own name and
  replayed later.

## Why a robot in the middle

The heroine never reads the program herself. The robot does, and it broadcasts each
instruction to her one at a time. That small detour is the whole point: there is a machine
between "what I asked" and "what happens", and it is the machine that does the work.

## Who it is for

A child and an adult, side by side, for ten minutes. The adult reads the labels out loud
and the child chooses. It is a conversation starter, not a course — there are no levels,
no score, no failure. There is one world, one demon, and as many attempts as the child wants.

The interface speaks French.
